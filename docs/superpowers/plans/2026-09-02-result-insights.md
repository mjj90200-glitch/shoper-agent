# 查询结果解读与可视化（P3）

> 状态：确定性摘要、自动轻量图表、CSV 导出已完成；真实结果端到端验证待 Docker 环境可用。

## 已完成

- 查询完成后进入 `analyze_result` 节点，只基于数据库实际返回行生成摘要；
- 自动识别数值列与标签列：时间类标签生成趋势图，其他分类标签生成对比图；
- 最多展示 12 个数据点，避免大结果集影响前端可读性；
- 前端展示可解释结论、图表和可导出的 CSV 结果；
- 解读逻辑为确定性代码，不调用 LLM，因此不会虚构数据结论。

## 仍待增强

- Docker 可用后验证真实结果表格、图表与 CSV；
- 对复杂多数值列结果增加用户可选指标；
- 在严格绑定真实结果数据的前提下，增加 LLM 经营洞察和下一步分析建议；
- 支持更丰富的图表类型，例如堆叠柱状图和占比图。
