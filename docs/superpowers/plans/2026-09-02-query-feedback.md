# 用户反馈闭环（P7）

> 状态：本地演示版已完成；真实问数端到端验证待 Docker 环境可用。

## 目标

将“查询结果是否有帮助”的主观判断转为可追溯数据，为后续评测集补充、Prompt 优化和检索优化提供真实样本。

## 已完成

- 查询 SSE 在开始时返回审计 ID，前端将其与本轮助手消息绑定；
- 用户可标记“有帮助”或“需改进”，并可补充最多 500 字的失败原因；
- 反馈更新 P6 的同一条审计记录，不另存完整查询结果；
- `PUT /api/audits/{audit_id}/feedback` 仅允许记录所属用户提交，运行中的记录不接受反馈；
- 审计面板展示评分和补充原因；
- 离线测试覆盖反馈保存和跨用户越权拒绝。

## 后续可扩展

- 汇总好评率、失败原因标签和高频失败问题；
- 将负反馈样本转为人工复核队列和离线评测候选集；
- 审计持久化到 MySQL 后加入管理员统计看板。
