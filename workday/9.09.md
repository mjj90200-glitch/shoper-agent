## 二、今日完成内容

### 1. 火山引擎 TTS 配置

新增结构化 TTS 配置：

```yaml
tts:
  api_key: ${oc.env:VOLCENGINE_TTS_API_KEY,''}
  voice_type: ${oc.env:VOLCENGINE_TTS_VOICE_TYPE,zh_female_vv_uranus_bigtts}
  resource_id: seed-tts-2.0
  endpoint: https://openspeech.bytedance.com/api/v3/tts/unidirectional
  timeout_seconds: 30
```

- 新版控制台使用 `X-Api-Key`，不需要旧版 APP ID 和 Access Token。
- API Key 只保存在后端 `.env`，不会发送给 React 前端。
- `.env.example` 和 README 已增加 TTS 配置说明。
- 将后端已经实际使用的 `httpx` 声明为直接依赖并更新 `uv.lock`。

### 2. 后端 TTS 服务

新增 `app/services/tts_service.py`：

- 清理 Markdown 标题、链接、代码块、表格分隔符和 Emoji。
- 将 GMV、SQL、人民币金额、百分比和日期转换为更适合朗读的文本。
- 按自然停顿切分长文本，每段最多 900 个 UTF-8 字节。
- 调用火山引擎 V3 HTTP 单向语音合成接口。
- 解析多行 JSON 响应并解码 Base64 MP3 音频分片。
- 多段合成时移除后续 MP3 的 ID3 元数据头，再拼接音频帧。
- 单次音频最大 10MB，超限时返回安全错误。
- 对相同音色和相同清洗文本提供最多 64 条进程内 LRU 缓存。
- 区分配置缺失、请求超时、HTTP 错误、网络错误和损坏响应。

### 3. 受保护的后端 API

新增：

```http
POST /api/tts/synthesize
Authorization: Bearer <登录令牌>
Content-Type: application/json

{"text":"华东地区销售额排名第一。"}
```

成功响应：

```text
Content-Type: audio/mpeg
Cache-Control: private, max-age=300
```

- 请求文本限制为 1～6000 字符。
- 接口复用现有登录认证，未登录用户不能消耗 TTS 额度。
- TTS 未配置返回 HTTP `503`，上游错误返回 HTTP `502`。
- 语音失败不修改问数、分析项目和追问数据。

### 4. 前端播放器

新增复用组件 `SpeechButton`：

- 支持首次合成并播放。
- 支持暂停、继续、停止和播放结束后重播。
- 新语音开始前自动停止旧语音，避免多个回答同时播放。
- 组件卸载或页面切换时中止未完成请求、停止音频并释放 Blob URL。
- 加载和错误均在按钮附近展示，不阻塞文字内容。

已经接入三个位置：

1. 快速问数：播放 AI 回复；存在数据洞察时优先播放洞察摘要。
2. 综合分析报告：播放概览、关键发现、行动建议和数据说明。
3. 分析追问：每条回答可以单独播放。
