## 二、产品决策

第一版语音能力只接入“快速问数”工作区，并遵循以下原则：

1. 不自动播放，必须由用户主动点击“朗读结论”。
2. 优先朗读 `analysis.summary`，即系统生成的数据摘要和关键结果。
3. 不朗读 LangGraph 节点、SSE 过程提示、SQL 或完整结果表。
4. 历史消息缺少结构化摘要时，以助手最终回复作为兼容兜底。
5. 一次只播放一条消息；播放新消息时自动停止旧音频。
6. TTS 失败只显示局部提示，不能影响文字结果、图表和后续问数。

本轮暂不把 TTS 接入数据分析工作区的综合报告和连续追问，也不开发自动播报、语音输入、声音复刻或实时双向语音。

## 三、后端开发

### 1. 配置模型

新增 TTS 配置：

- `VOLCENGINE_TTS_API_KEY`
- `VOLCENGINE_TTS_VOICE_TYPE`
- `VOLCENGINE_TTS_RESOURCE_ID`
- `VOLCENGINE_TTS_BASE_URL`
- 请求超时和最大文本长度

API Key 只从后端环境读取，不进入 React 的 `VITE_*` 环境变量，也不写入前端请求代码。

### 2. 火山引擎 TTS 服务

新增 `app/services/tts_service.py`：

- 使用 V3 HTTP Chunked/SSE 单向流式接口。
- 使用 `X-Api-Key`、资源 ID 和请求 ID 完成鉴权与追踪。
- 逐条读取 `data:` 事件，解码并拼接 Base64 MP3 音频片段。
- 忽略 `event:`、心跳和其他 SSE 控制行。
- 对无效业务状态码、损坏 Base64、空音频、网络超时和 HTTP 错误进行统一映射。
- 单次音频最大 10MB，避免异常上游响应持续占用内存。
- 使用 5 分钟、最多 32 条的内存缓存减少重复合成请求。

### 3. 播报文本处理

合成前会清理 Markdown 标记、代码块、内联代码、图片、链接、URL、表格分隔符和不适合朗读的符号。同时规范化人民币金额、百分比和日期，使中文播报更自然。单次语音文本限制为 600 个字符，避免把长表格或大段技术内容提交给语音服务。

### 4. 鉴权接口

新增：

```http
POST /api/tts/synthesize
Authorization: Bearer <access_token>
Content-Type: application/json

{"text":"语音功能测试成功。"}
```

成功返回 `audio/mpeg`。未登录返回 401，未配置密钥返回 503，上游语音服务失败返回 502。

## 四、前端开发

新增 `SpeechControls` 组件并接入 `MessageBubble`：

- 助手问数完成后显示带文字的“朗读结论”按钮。
- 生成过程中显示加载状态。
- 播放中可以暂停，暂停后可以继续，也可以随时停止。
- 浏览器通过 Blob URL 播放 MP3，结束或组件卸载后立即释放 URL。
- 使用 `AbortController` 取消尚未完成的语音请求。
- 切换消息播放时终止上一条音频。
- 修复 React StrictMode 模拟卸载后控件状态无法更新的问题。

最初按钮要求消息同时具有 `analysis.summary` 和 `result`，导致历史会话和部分完成消息看不到入口。现已改为：所有成功完成且可读的问数回复均显示按钮，结构化摘要优先，最终回复兜底。

## 五、问题与修复记录

### 1. TTS 首次真实请求返回 502

现象：后端提示“语音服务返回了无法解析的数据”。

原因：火山引擎返回标准 SSE 流，其中除 `data:` 外还可能包含 `event:` 等控制行；旧解析逻辑把控制行当成 JSON。

修复：只消费 `data:` 音频事件，忽略其他 SSE 行，并增加专门的回归测试。

### 2. 页面看不到语音按钮

原因：按钮显示条件过严，仅覆盖带完整结果对象和分析摘要的新消息。

修复：成功完成的问数助手消息均可显示语音入口；仍优先使用摘要，保证新问数只朗读关键结论。

### 3. Python 依赖工具问题

本机项目使用 Python 3.14.7。直接执行 `uv run pytest` 会尝试重新构建 `asyncmy`，并要求本机存在 C++ Build Tools。为避免重装业务依赖，本轮使用 `uv run --no-sync --with pytest python -m pytest` 完成测试。该问题属于现有 Windows/Python 3.14 环境依赖兼容问题，不是 TTS 业务代码错误。

## 八、数据与隐私边界

用户点击朗读后，当前结论文本会发送到配置的火山引擎语音服务。项目进入正式环境前需要完成：

- 明确的用户告知与语音开关。
- 第三方供应商和数据出境评估。
- HTTPS、密钥托管、额度限制和调用审计。
- 对敏感字段和不允许外发的业务结论实施服务端策略。

当前实现已经避免自动播放，也不会主动发送流程、SQL 或完整结果表，但“结论是否允许发送到第三方”仍需要由部署方的数据治理规则决定。
