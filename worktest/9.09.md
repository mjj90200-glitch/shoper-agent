## 二、后端测试要求

### TC-TTS-BE-001：登录鉴权

步骤：不携带登录令牌调用 `POST /api/tts/synthesize`。

预期：返回 HTTP `401`，不调用火山引擎，不产生语音费用。

### TC-TTS-BE-002：成功合成

步骤：登录后提交有效中文文本。

预期：

- 返回 HTTP `200`。
- `Content-Type` 为 `audio/mpeg`。
- 响应以合法 MP3/ID3 数据开头并能播放。
- 响应头不包含 API Key。

### TC-TTS-BE-003：配置缺失

分别移除 `VOLCENGINE_TTS_API_KEY` 和 `VOLCENGINE_TTS_VOICE_TYPE` 后请求接口。

预期：返回 HTTP `503`，提示检查配置；文字问数和数据分析仍然可用。

### TC-TTS-BE-004：上游异常

模拟请求超时、网络中断、HTTP 非 2xx、无额度、音色无权限和损坏响应。

预期：返回 HTTP `502` 和可理解的中文错误，不返回密钥、堆栈或上游二进制数据。

### TC-TTS-BE-005：请求边界

测试空文本、仅 Markdown 代码块、超过 6000 字符的文本。

预期：空文本和超长文本由 API 校验拒绝；清洗后无有效内容返回安全错误。

## 三、文本清洗测试要求

### TC-TTS-TEXT-001：Markdown 与代码

输入包含标题、列表、Markdown 链接、URL、表格和 SQL 代码块的报告。

预期：朗读业务结论和链接名称，不朗读 Markdown 符号、URL 或代码块。

### TC-TTS-TEXT-002：数据规范化

输入：

```text
2026-09-09，GMV 为 ¥12,358.50，同比增长 18.6%。
```

预期清洗语义：

```text
2026年9月9日，成交总额为12358.50元，同比增长百分之18.6。
```

### TC-TTS-TEXT-003：长文本分段

输入超过 900 UTF-8 字节的中文报告。

预期：优先按句号、问号、感叹号、分号和换行拆分；每段不超过 900 字节；拼接后文字不丢失、不重复。

### TC-TTS-TEXT-004：多段 MP3 拼接

预期：第一段保留 ID3，后续分段移除 ID3 后再拼接；最终浏览器能够从头播放到尾。

## 四、前端手工验收

### TC-TTS-FE-001：快速问数播放

1. 完成一次快速问数。
2. 点击机器人回复右上角语音按钮。
3. 依次测试暂停、继续、停止和重播。

预期：有洞察时朗读洞察摘要；没有洞察时朗读回答正文；不朗读 SQL 和完整表格。

### TC-TTS-FE-002：综合报告播放

1. 完成一个数据分析项目。
2. 点击“播放报告”。

预期：按概览、关键发现、行动建议、数据说明的顺序播放，不朗读原始表格和技术字段。

### TC-TTS-FE-003：追问回答播放

发送至少两条分析追问，分别点击每条回答的语音按钮。

预期：只播放对应回答；播放第二条时自动停止第一条。

### TC-TTS-FE-004：页面切换

在播放过程中切换会话、分析项目或工作区。

预期：旧音频立即停止，Blob URL 被释放，不继续后台播放。

### TC-TTS-FE-005：失败不阻塞主功能

断网或配置错误时点击播放。

预期：按钮附近显示错误；原回答、表格、图表、追问和输入框仍然可用。

### TC-TTS-FE-006：重复操作

快速连续点击同一播放按钮和不同回答的播放按钮。

预期：不会出现多段音频重叠、重复请求风暴或无法停止的音频。
