# 9 月 3 日：P8–P10 TDD 测试需求

> 测试范围：SQLite Checkpointer 持久化、SQLite 审计/反馈持久化、历史会话管理、管理员质量汇总。
>
> 执行原则：先完成 A 部分自动化测试，再进行 B 部分真实服务重启验证，最后进行 C 部分前端验收。不得仅凭接口返回 200 判定通过；必须同时校验数据隔离、重启后的数据保留和删除边界。

## A. 必须补齐的自动化测试

### A1. SQLite Checkpointer 持久化

- [ ] 使用临时 SQLite 文件执行第一轮图调用，写入带 `thread_id` 的状态。
- [ ] 关闭第一个 `AsyncSqliteSaver` 连接，重新创建新的连接和图实例。
- [ ] 使用相同 `thread_id` 调用 `aget_state`，断言历史 `messages` 与 `resolved_query` 仍存在。
- [ ] 使用不同 `thread_id`，断言无法读取前一会话历史。
- [ ] 使用不同用户前缀但相同 `session_id`，例如 `admin:session-1` 与 `analyst:session-1`，断言状态隔离。
- [ ] 断言 SQLite 文件创建于 `data/langgraph-checkpoints.sqlite`，且 `data/` 被 `.gitignore` 忽略。

### A2. 审计与反馈 SQLite 持久化

- [ ] `QueryAuditService.start()` 创建审计记录后，断言 `chat_sessions` 与 `query_audit_log` 均写入对应用户和会话。
- [ ] 依次消费 `query_context`、`sql`、`result` SSE 事件并调用 `finish()`，断言改写问题、SQL、行数、成功状态、耗时被写入数据库。
- [ ] 关闭并重新初始化审计服务后，`list_for_user()` 仍能读取此前记录。
- [ ] 提交“有帮助”和“需改进 + 原因”反馈后，断言评分、原因、反馈时间持久化。
- [ ] 使用其他用户提交同一 `audit_id` 的反馈，断言返回 `None` / API 返回 `404`。
- [ ] 对 `running` 状态审计记录提交反馈，断言被拒绝。
- [ ] 断言审计表不保存完整 `result.data`，只保存 `result_row_count`，避免重复存储业务数据。

### A3. 会话管理 API

- [ ] 未携带 Bearer Token 调用 `/api/sessions`，断言 HTTP `401`。
- [ ] 当前用户仅能获取自己的会话列表；另一用户的会话不得出现在结果中。
- [ ] `GET /api/sessions/{session_id}` 仅返回该用户该会话的审计型历史记录。
- [ ] 跨用户读取会话详情，断言 HTTP `404`，避免暴露会话是否存在。
- [ ] `PATCH /api/sessions/{session_id}` 可修改标题；空标题和超过 80 字标题应返回请求校验错误。
- [ ] 跨用户重命名或删除会话，断言 HTTP `404`。
- [ ] 删除会话后，`chat_sessions` 和该会话的 `query_audit_log` 均不存在。
- [ ] **待补实现后的回归项**：删除会话后，同一用户同一 `session_id` 的 LangGraph checkpoint 也必须被物理删除，不能通过旧 ID 继续继承上下文。

### A4. 管理员质量汇总

- [ ] 准备成功、失败、未完成、正反馈、负反馈等多类审计样本。
- [ ] 管理员调用 `/api/audits/quality-summary`，断言总问数、完成数、成功率、平均耗时、反馈数、好评率计算正确。
- [ ] 无反馈数据时，好评率应为 `0`，不得除零或返回 `NaN`。
- [ ] 普通分析员、区域经理调用质量汇总接口，断言 HTTP `403`。
- [ ] 负反馈列表最多返回最近 10 条，且包含问题、用户、反馈原因和时间。

## B. Docker 与真实服务重启验收

> 前提：Docker、MySQL、Qdrant、Elasticsearch、Embedding、真实 LLM API Key 均可用。

### B1. 持久化追问

1. 以 `admin` 登录，记录浏览器当前 `session_id`。
2. 提问：`统计华东地区 2025 年第一季度销售额`，等待成功返回。
3. 重启 FastAPI，**不要**清除浏览器 localStorage。
4. 使用同一账号和同一会话追问：`那华北呢？`。

验收：改写问题包含“华北、2025 年第一季度、销售额”；最终 SQL 语义正确；不是把追问当作无上下文新问题。

### B2. 审计、反馈与会话重启恢复

1. 完成一条问数并标记“需改进”，填写原因。
2. 重启 FastAPI。
3. 重新登录同一用户，打开“查询审计”和“历史”。

验收：审计记录、最终 SQL、反馈评分、反馈原因、会话标题均存在；其他账号不可见。

### B3. 删除边界

1. 删除一条历史会话。
2. 刷新页面并重新登录。
3. 检查会话列表、审计面板和 SQLite 数据。

验收：会话元数据与审计记录均被删除。Checkpointer 物理删除当前尚未实现，测试应记录为预期失败，待开发修复后转为通过。
